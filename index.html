Current model

Combat score: R = Aart/Dart + Ainf/Dinf + Acav/Dcav. A score below 0.5 predicts a defender victory; defender losses are approximately 2R.

For attacker victories (R ≥ 0.5), the winner-loss equation is still provisional. It is anchored to the real max-wall attacker victory with ~89.16% attacker losses. More attacker-win reports will let us replace this fitted curve with the game's actual relationship.
